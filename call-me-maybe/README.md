# Call-Me-Maybe

## - Description -
Call-Me-Maybe è un progetto in cui dobbiamo elaborare i dati di due JSON attraverso l'LLM. Infatti passiamo al programma due file JSON: il primo contenente i prompt, il secondo contenente il nome della funzione, la descrizione, i parametri e il tipo, il tipo di ritorno. L'obbiettivo è prendere questi due file, passarli all'LLM e ritornare un JSON con nome, prompt e parametri della funzione elaborata.
