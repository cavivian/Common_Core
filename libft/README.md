# *Libft* 

_________

## Descrizione
### **Libft** primo progetto della 42 che consiste nel ricreare una libreria in C personalizzata; Infatti sono state aggiunte funzioni utili per gestire le stringhe, la memoria e le liste collegate. 

### Funzioni sui caratteri: `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, `ft_isprint`, `ft_toupper`, `ft_tolower`

### Funzioni sulle stringhe: `ft_strlen`, `ft_strlcpy`, `ft_strlcat`, `ft_strdup`, `ft_strchr`, `ft_strrchr`, `ft_strncmp`, `ft_strnstr`, `ft_substr`, `ft_strjoin`, `ft_strtrim`, `ft_split`, `ft_itoa`, `ft_strmapi`

### Funzioni sulla memoria: `ft_memset`, `ft_bzero`, `ft_memcpy`, `ft_memmove`, `ft_memchr`, `ft_memcmp`, `ft_calloc`

### Funzioni per File Descriptor: `ft_putchar_fd`, `ft_putstr_fd`, `ft_putendl_fd`, `ft_putnbr_fd`

### Funzioni sulle liste collegate: `ft_lstnew`, `ft_lstadd_front`, `ft_lstadd_back`, `ft_lstsize`, `ft_lstlast`, `ft_lstdelone`, `ft_lstclear`, `ft_lstiter`, `ft_lstmap`
__________

## Istruzioni
### 1. Compilare il programma:

```C
make
``` 

### 2. Eliminare file oggetto: 

```C
make clean 
``` 

### 3. Eliminare l'eseguibile:
```C
make fclean 
```
